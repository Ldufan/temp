📋 设备数据协议说明
Service UUID 00000318-0000-1000-8000-00805f9b34fb
有效数据长度6 Bytes
Byte0温度符号 00=正 / 01=负
Byte1温度整数(16进制)
Byte2温度小数 ÷100
Byte3湿度整数(16进制)
Byte4湿度小数 ÷100
Byte5电池电量 %
解析示例：
原始广播：0x001A45322A64
符号：正(00) | 温度=26 + 69/100 = 26.69℃
湿度=50 + 42/100 = 50.42% | 电量=100%

ℹ️ 使用说明

1. 仅支持 Android Chrome 浏览器，必须 HTTPS 访问
2. 手机开启蓝牙+定位，授予全部权限
3. 单次仅可连接一台 RL_HT_Tag 设备
4. 断开后自动重试重连，超出范围恢复后自动采集
5. 数据存储在浏览器本地，清空缓存会丢失记录
